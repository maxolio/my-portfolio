# 🌐 Personal Developer Portfolio — Сайт-портфолио фронтенд-разработчика

Минималистичный сайт-портфолио, созданный для подведения итогов первого года обучения фронтенд-разработке. Проект призван наглядно продемонстрировать навыки верстки, работы с чистым JavaScript (без использования фреймворков), архитектурой БЭМ и проектирования пользовательских интерфейсов.

---

## ✨ Ключевые особенности
* **Переключение тем (Dark / Light)** — поддержка темной и светлой темы с сохранением выбора пользователя в `localStorage` и поддержкой системных настроек ОС (`prefers-color-scheme`).
* **Мультиязычность (RU / EN)** — динамическая смена языка интерфейса через JS-словарь "на лету" без перезагрузки страницы.
* **Чистый стек без фреймворков** — демонстрация фундаментальных знаний HTML, SCSS и Vanilla JS.
* **Адаптивный & Доступный дизайн** — корректное отображение на всех типах устройств с соблюдением стандартов доступности (Accessibility).

---

## 🛠️ Стек технологий и инструменты

* **HTML5** — семантическая и доступная разметка (использование тегов `<header>`, `<main>`, `<section>`, `<footer>` и атрибутов `data-*`).
* **CSS3 / SCSS** — модульная стилизация, реализация темной/светлой темы через CSS Custom Properties (переменные), построение сеток (Flexbox, Grid).
* **BEM (БЭМ)** — методология именования классов для создания поддерживаемой структуры стилей.
* **JavaScript (ES6+)** — логика переключения тем и языков, манипуляции с DOM, работа с Web Storage API (`localStorage`).
* **NPM & Tooling** — сборка и слежка за SCSS (`sass`), локальный сервер с автоперезагрузкой (`live-server`).
* **Git & GitHub** — контроль версий, история разработки и публикация проекта.
* **Repomix** — упаковывание контекста проекта для анализа с помощью ИИ-ассистентов.
